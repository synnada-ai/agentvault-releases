# Agent Vault downloads

Signed and notarized native macOS installers for Agent Vault.

[Download for Mac](https://github.com/synnada-ai/agentvault-releases/releases/download/v0.1.1/Agent-Vault-0.1.1-arm64.dmg)

Requires macOS 15 or later on Apple silicon. Open the disk image and drag Agent Vault to Applications.

The application and installer are signed by Synnada, Inc. and notarized by Apple. Checksums and release notes accompany each release. Application source code and user archives are not stored in this repository.

[Website](https://agentvault.run/)
