# AgentVault downloads

Signed and notarized native macOS installers for AgentVault.

[Download for Mac](https://github.com/synnada-ai/agentvault-releases/releases/download/v0.1.0/Vault-0.1.0-arm64.dmg)

Requires macOS 15 or later on Apple silicon. Open the disk image and drag Vault to Applications.

The application and installer are signed by Synnada, Inc. and notarized by Apple. Checksums and release notes accompany each release. Application source code and user archives are not stored in this repository.

[Website](https://agentvault.run/)
